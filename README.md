本組新增的功能：
- 隨機選擇英文單字出題
- 產生中文四選一答案
- 隨機排列答案選項
- 使用 A、B、C、D 作為選項標籤
- 接收使用者輸入答案
- 自動判斷答案是否正確
- 顯示答題結果
- 答錯時顯示正確答案
- 預設進行 10 題測驗
- 統計答對題數
- 顯示測驗準確率
- 支援透過 JSON 擴充單字內容
